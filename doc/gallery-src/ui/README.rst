The ARMI UI
-----------

ARMI's browser-based UI shows and edits a case's inputs, runs the case, and shows what the run wrote. These are
screenshots rather than plots made when the documentation is built; start it with ``python -m armi gui`` on a
settings file, a blueprints file or a run's database. See :doc:`/user/ui` for a tour.
